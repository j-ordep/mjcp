# Backend Go anterior

Implementação anterior em Go/Chi com PostgreSQL, preservada no repositório.
Ela não é o backend integrado ao mobile atual e não representa a API Fastify planejada.

Dependências em `go.mod`; configuração em `config/config.go`.
As regras do produto ficam em [REGRAS_DE_NEGOCIO](../backend-node/docs/REGRAS_DE_NEGOCIO.md).
O trabalho da API está no [TASK do backend](../backend-node/docs/TASK.md).
