# Base web anterior

Base em Next.js/TypeScript, com página inicial e cliente HTTP.
Fica fora do ciclo atual do produto. O diretório não comprova fluxos de gestão concluídos.

Para explorar a base na pasta `web`:

```sh
npm install
npm run dev
```

Dependências e comandos em `package.json`.
Regras do produto em [REGRAS_DE_NEGOCIO](../backend-node/docs/REGRAS_DE_NEGOCIO.md).
Pendências em [TASK do backend](../backend-node/docs/TASK.md) e [TASKS do mobile](../mobile/docs/TASKS.md).
